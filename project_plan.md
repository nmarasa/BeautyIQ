# BeautyIQ - project plan
## project goal

build an interactive dashboard that analyzes beauty product data and costumer reviews to identify like, dislike, and still want from beauty products.

goal is to turn customer feedback into useful business recommendations rather than only creating charts or cleaning a dataset

## main business question
what beauty product categories or products show strong customer demand but recurring complaints that could reveal oppurtunities for product improvement?

## target user
this dashboard is intended for people working in areas like:

- product analytics 
- consumer insights
- marketing analytics 
- merchandising
- beauty brand strategy

## data i want
ideally the dataset should include:
- skin tyle
- hair type
- verified purchase
- recommendation status
- helpful votes

## core features

### 1. market overview
show things like:
- total products
- total brands
- average pricing
- product/category distribution
- highest rated brands or categories

### 2. product explorer
allow users to filter and compare products by things like: 
- brand
- category
- pricing
- rating

### 3. review analysis
analyze customer review text to identify:
- positive feedback 
- negative feedback
- common praise
- common complaints
- recurring customer themes

possible themes could include: 
- dryness
- pigmentation
- longevity
- packaging
- irritation
- value

### 4. oppurtunity finder
use product meterics and customer feedback together to identify possible product oppurtunities

ex. 
if affordable lip products recieve good ratings for pigmentation but customers frequently complain ab dryness, that may suggest an oppurtunity for a hydrating, long-wear lippie

## tools
planned tools:

- python
- pandas
- sql / sqlite
- jupyter notebook
- streamlit
- matplotlib and/or plotly
- basic sentiment or text analysis
- git / github

## MVP
first complete version should include:

- a strong dataset
- cleaned data
- sql, python, review sentiment/theme analysis
- interactive streamlit dashboard
- product oppurtunity findings
- professional README

## stretch features
only after MVP works:

- more advanced NLP
- automeated oppurtunity scoring
- competitor comparisons 
- multiple datasets
- API integration
- AI-generated review summaries
